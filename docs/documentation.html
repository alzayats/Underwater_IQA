Documentation

Complete guide for installing and using Underwater_IQA

Installation

Prerequisites

  • Python 3.8 or higher
  • pip or conda package manager
  • Optional: GPU support (NVIDIA CUDA 11.0+ for deep learning)

Via PyPI (Recommended)

pip install underwater-iqa

From Source

The source repository is private until the manuscript is published. The commands below will work once it is released.

git clone https://github.com/open-AIMS/UNIQAT.git
cd UNIQAT
pip install -e .

GPU Support (Optional)

For GPU acceleration with deep learning models:

pip install underwater-iqa[gpu]
# or install PyTorch manually:
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118

Verify Installation

python -c "from underwater_iqa import UnderwaterImageAssessor; print(' Installation successful!')"

Quick Start

Assess a Single Image (Python API)

from underwater_iqa import UnderwaterImageAssessor

# Initialize assessor
assessor = UnderwaterImageAssessor(method='hybrid')

# Assess an image
results = assessor.assess_image('path/to/image.jpg')

# Access results
print(f"Overall Quality: {results['overall_quality']}")
print(f"Blue Water Severity: {results['blue_water_severity']}")
print(f"Feature Usefulness: {results['feature_usefulness']}")
print(f"Marine Science Value: {results['marine_science_value']}")

Assess a Single Image (CLI)

assess-image path/to/image.jpg --method hybrid --visualize

Batch Processing (100+ images)

from underwater_iqa import BatchProcessor

processor = BatchProcessor(method='deep-learning', num_workers=8)
results = processor.process_directory('path/to/images/')
processor.export_results('results.csv')

Batch Processing (CLI)

assess-batch path/to/images/ --method deep-learning --num-workers 8 --output results.csv

Assessment Methods

Traditional Metrics

from underwater_iqa import UnderwaterImageAssessor

assessor = UnderwaterImageAssessor(method='traditional')
results = assessor.assess_image('image.jpg')

# Access detailed metrics
for metric_category, values in results['detailed_metrics'].items():
    print(f"{metric_category}: {values}")

Characteristics:

  • Fully interpretable results
  • No GPU required
  • 37 hand-crafted metrics
  • Throughput: 7.9 images/sec on a 64 core node with 48 workers, measured over 130,845 survey images
  • Single core: 0.40 images/sec, roughly 2.5 s per 2.8 megapixel image

Deep Learning

assessor = UnderwaterImageAssessor(
    method='deep-learning',
    model='efficient-net',  # or 'underwater-quality-net', 'vit', 'multi-metric'
    device='cuda'
)
results = assessor.assess_image('image.jpg')

Characteristics:

  • Single forward pass per image
  • Requires GPU for best performance
  • 4 model architectures available
  • Forward pass: 934 to 2,715 images/sec on an RTX 4090, depending on architecture
  • Fidelity to the traditional metrics depends entirely on your training data. Models are not shipped pre-trained

Hybrid Ensemble (Recommended)

assessor = UnderwaterImageAssessor(
    method='hybrid',
    dl_weight=0.6,  # 60% deep learning
    traditional_weight=0.4,  # 40% traditional metrics
    model='efficient-net'
)
results = assessor.assess_image('image.jpg')

Characteristics:

  • Retains the interpretability of the traditional metrics
  • Combines speed and interpretability
  • Configurable weighting
  • Throughput is bounded by the traditional branch, so expect the traditional figure
  • Useful while you are establishing how far to trust a model you trained yourself

Visualization Output

When visualizations are enabled (--visualize flag), get an 11-panel report showing:

  • Original image
  • Edge detection
  • Color space analysis (RGB, HSV, LAB)
  • Histogram analysis
  • Feature detection
  • Quality metrics summary

Configuration Options

Assessor Configuration

assessor = UnderwaterImageAssessor(
    method='hybrid',              # 'traditional', 'deep-learning', 'hybrid'
    model='efficient-net',         # DL model architecture
    device='cuda',                 # 'cuda' or 'cpu'
    dl_weight=0.6,                 # 0-1, weight of DL in hybrid
    traditional_weight=0.4,        # 0-1, weight of traditional in hybrid
    batch_size=32,                 # for batch processing
    num_workers=4,                 # parallel processing workers
    visualize=True,                # generate visualization reports
    output_format='json'            # 'json', 'csv', 'dict'
)

Batch Processing Configuration

processor = BatchProcessor(
    method='deep-learning',
    model='vit',
    num_workers=8,                # CPU cores for parallel processing
    device='cuda',
    batch_size=64,                # GPU batch size
    visualize=True,
    export_format='csv',          # 'csv', 'json', 'both'
    progress_bar=True,
    sample_images=None            # None or number to sample
)

Advanced Usage

Custom Metric Weighting

from underwater_iqa import MetricWeighter

weighter = MetricWeighter({
    'color_saturation': 1.5,      # emphasize color metrics
    'sharpness': 1.2,
    'contrast': 1.0,
    'blue_water_detection': 2.0   # heavily weight blue water problem
})

results = assessor.assess_image('image.jpg', metric_weights=weighter)

Export Results

from underwater_iqa import ResultsExporter

exporter = ResultsExporter()

# Export to CSV
exporter.to_csv(results, 'results.csv')

# Export to JSON
exporter.to_json(results, 'results.json')

# Export with visualizations
exporter.to_html_report(results, 'report.html')

Image Enhancement Suggestions

if results['blue_water_severity'] > 7:

Troubleshooting

GPU Memory Issues

If you get CUDA out-of-memory errors, reduce batch size:

assessor = UnderwaterImageAssessor(method='deep-learning', batch_size=8)

Slow Processing

Use deep learning for faster processing:

assessor = UnderwaterImageAssessor(method='deep-learning', device='cuda')

Import Errors

Make sure installation completed successfully:

pip install --upgrade underwater-iqa

Model Download Issues

Pre-download models manually:

from underwater_iqa import PretrainedModels
PretrainedModels.download_all()
