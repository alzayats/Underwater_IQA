Methodology

Technical details and algorithms behind Underwater_IQA

Overview

Underwater_IQA uses a comprehensive, multi-faceted approach to assess underwater image quality. The system combines:

42 Metrics

Hand-crafted metrics based on image science principles

4 DL Models

Deep learning architectures trained on underwater images

Multi-Score System

Four quality dimensions for comprehensive assessment

Ensemble Approach

Hybrid method combining traditional and DL approaches

The 42-Metric System

Underwater_IQA evaluates images using 42 hand-crafted metrics organized into 10 categories:

1. Color and Saturation (5 metrics)

  • Color Saturation Index: Measures overall color vividness
  • Red Channel Intensity: Evaluates warm color preservation
  • Color Variance: Assesses color diversity
  • Blue-Green Ratio: Detects blue water color cast
  • Color Histogram Spread: Measures color distribution

2. Contrast and Brightness (6 metrics)

  • Contrast Ratio: Object-background separation
  • Brightness Level: Overall image luminance
  • Contrast-to-Noise Ratio (CNR): Distinguishability in noisy conditions
  • Dynamic Range: Span from darkest to brightest pixels
  • Michelson Contrast: Visibility contrast measure
  • Histogram Peak Ratio: Pixel value distribution clustering

3. Sharpness and Clarity (7 metrics)

  • Laplacian Variance: Edge detection-based sharpness
  • Tenengrad Measure: Gradient-based focus quality
  • Sobel Edge Strength: Edge definition strength
  • Brenner Focus Measure: Normalized sharpness assessment
  • Blur Detection: Identifies blurred regions
  • Fine Detail Preservation: Small feature clarity
  • Texture Clarity: Surface pattern visibility

4. Frequency Domain Analysis (4 metrics)

  • High-Frequency Energy: Detail preservation in FFT domain
  • Power Spectrum Spread: Frequency content diversity
  • Frequency Peak Sharpness: Concentrated frequency energy
  • Mid-Frequency Balance: Medium detail presence

5. Edge Detection (3 metrics)

  • Edge Density: Number and prominence of edges
  • Edge Sharpness: Edge definition clarity
  • Edge Continuity: Connected edge structures

6. Noise Detection (4 metrics)

  • Noise Level: Estimated random pixel variations
  • Signal-to-Noise Ratio (SNR): Useful signal vs noise
  • Speckle Noise Detection: Salt-and-pepper noise presence
  • Noise Variance: Spatial distribution of noise

7. Color Space Analysis (3 metrics)

  • HSV Saturation: Color space-based saturation measure
  • LAB Color Distribution: Perceptual color space analysis
  • Color Space Spread: Diversity in color space representation

8. Structural Similarity (2 metrics)

  • SSIM Index: Structural similarity measure
  • Luminance Correlation: Brightness pattern similarity

9. Histogram Analysis (2 metrics)

  • Histogram Entropy: Information content in pixel distribution
  • Histogram Smoothness: Gradual vs abrupt value changes

10. Custom Underwater Metrics (1 metric)

  • Underwater Color Image Quality Evaluation (UCIQE): Underwater-specific metric

Multi-Score Assessment System

Each image receives four quality scores:

Overall Quality (0-100)

Weighted combination of all 42 metrics. Provides a single quality score considering color, contrast, sharpness, and other factors.

Calculation: Normalized mean of all metric scores with category weighting.

Blue Water Severity (0-10)

Specific assessment of the blue-green color cast and color loss problem characteristic of underwater images.

Calculation: Derived from color saturation, red channel intensity, and blue-green ratio metrics.

  • 0-3: Minimal blue water problem
  • 4-6: Moderate blue water problem
  • 7-10: Severe blue water problem

Feature Usefulness (0-100)

Suitability for computer vision tasks (object detection, segmentation, feature extraction). Emphasizes clarity, contrast, and edge definition.

Calculation: Weighted focus on sharpness, edge detection, and contrast metrics.

Marine Science Value (0-100)

Research value for marine biology and species identification. Emphasizes color preservation and overall visibility.

Calculation: Weighted focus on color saturation, clarity, and overall quality.

Deep Learning Pipeline

Four Model Architectures

1. UnderwaterQualityNet (Custom CNN)

Custom convolutional neural network designed specifically for underwater image assessment.

  • Architecture: 5-layer CNN with batch normalization
  • Input: 256×256 RGB images
  • Output: 4 quality scores (overall, feature, marine science, blue water severity)
  • Parameters: ~2.5M trainable parameters
  • Speed: ~2ms per image on RTX 3090

2. EfficientNet (Mobile-Optimized)

Lightweight architecture for deployment on edge devices.

  • Architecture: EfficientNet-B2 with underwater-specific fine-tuning
  • Input: 260×260 RGB images
  • Parameters: ~9.1M trainable parameters
  • Speed: ~1.5ms per image on RTX 3090
  • Benefits: Lightweight, mobile-deployable, high accuracy

3. Vision Transformer (ViT)

Transformer-based architecture for advanced feature extraction.

  • Architecture: ViT-B with patch-based attention
  • Input: 224×224 RGB images
  • Parameters: ~86M trainable parameters
  • Speed: ~3ms per image on RTX 3090
  • Benefits: Superior accuracy, captures long-range dependencies

4. MultiMetricPredictor (Ensemble Base)

Multi-branch network that predicts individual metric scores instead of aggregate scores.

  • Architecture: Multi-branch CNN with separate heads for metric categories
  • Output: Individual scores for each metric category
  • Speed: ~4ms per image on RTX 3090
  • Benefits: Interpretable outputs, metric-level insights

Training Approach

  • Dataset: Underwater images with human quality annotations
  • Training Labels: Generated using traditional 42-metric system
  • Loss Function: Mean Absolute Error (MAE) for regression
  • Augmentation: Color jittering, rotation, flipping, noise addition
  • Validation: Correlation and MAE metrics against ground truth

Hybrid Ensemble Approach

The hybrid approach combines traditional metrics and deep learning predictions to achieve the best balance of accuracy, interpretability, and speed.

Algorithm

Hybrid Score = (DL Weight × DL Score) + (Traditional Weight × Traditional Score)
Default: 60% Deep Learning + 40% Traditional Metrics
Configurable for different use cases

Advantages

Accuracy

Combines strengths of both approaches for superior accuracy

Interpretability

Traditional metrics provide explainability alongside DL speed

Speed

Faster than pure traditional metrics, slower but more reliable than pure DL

Flexibility

Configurable weights for different prioritization needs
